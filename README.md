
# 4th Semester College Activities – Software Development

This repository contains **activities, exercises, projects, and study materials**
developed during the **4th semester** of my **Analysis and Development of Systems (ADS)** course.

The content covers topics related to **software engineering, web development,
databases, distributed systems, testing, and human-computer interaction**, as well as
elective subjects.

---

## 📂 Contents

| Area | Subjects | Description |
|-----|--------|-------------|
| **Software Engineering** | Software Development Process I, Software Project I | Activities and projects focused on software development methodologies, requirements, planning, and project structuring. |
| **Web Development** | Web Systems Development | Exercises and projects related to web application development concepts and practices. |
| **Databases** | Database Management | Practical activities involving database concepts, modeling, and management. |
| **Distributed Systems** | Distributed Systems Development | Study materials and exercises focused on distributed computing concepts. |
| **Software Quality** | Software Testing | Activities related to testing techniques, test planning, and quality assurance. |
| **Human-Computer Interaction** | Interface Homem-Computador | Content focused on usability, user experience, and interface design principles. |
| **Maintenance & Configuration** | Software Maintenance and Configuration | Exercises related to software evolution, maintenance practices, and configuration management. |
| **Elective Subjects** | Emerging Technologies, Special Topics, LIBRAS | Complementary content from optional subjects studied during the semester. |

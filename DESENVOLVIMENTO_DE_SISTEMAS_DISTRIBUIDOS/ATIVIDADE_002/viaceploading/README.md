# ViaCEP Loading

Aplicação Java em console que consulta CEPs usando a API ViaCEP.

## Tecnologias
- Java 25
- Maven
- Gson

## Descrição
A aplicação solicita um CEP ao usuário, realiza a consulta em uma thread
separada e exibe uma animação enquanto aguarda a resposta da API.

## Exemplo
Entrada: 74735060  
Saída: Logradouro, bairro, cidade e UF
